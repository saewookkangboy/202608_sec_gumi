# Korean phrases to cut or replace

Apply with [phrases.md](phrases.md) and [structures.md](structures.md). Technical terms stay when they name a file, field, or protocol.

## Throat-clearing

| Cut or replace | Use instead |
|---|---|
| 이어집니다 | End the sentence or state the next step directly |
| 한눈에 보는 | Drop the heading filler; name the section (예: `5일 흐름`) |
| 무엇을 하는 저장소인가 | `개요` |
| 핵심 (수식어) | Drop unless it labels a required artifact type |
| 요약하면 / 정리하면 | State the list |
| 마지막으로 | Drop |
| 다음으로 넘어가세요 | `다음 질문으로 넘어가세요` |
| 실무 적용 가능한 | Drop or name the deliverable (`최종 결과물`) |
| 상세 … 별도 요청 시 보강 | Drop meta promises |

## Filler connectors

| Avoid when filler | Prefer |
|---|---|
| ~를 기반으로 (Day X를 기반으로) | `Day X에서`, `Day X와`, or merge clauses |
| ~와 함께 (갱신·완성) | Split: `도 갱신`, `완성합니다` |
| 사람·AI가 함께 읽는 | `사람·AI용` |

## Dramatic framing

| Avoid | Prefer |
|---|---|
| 심장입니다 / 핵심입니다 | Drop or name the section |
| 궁극 / 혁신 / 탁월 / 강력한 | Drop |
| 이를 통해 / 이러한 | Drop or name the thing |

## Keep (not slop)

- `합성 데이터 기반 교육 결과` (면책 문구)
- `표준 템플릿 기반 견적` (도메인)
- `Python 표준 라이브러리 기반 검색` (기술 스택)
- `코드 기반 manager 패턴` (아키텍처 용어)
- `구체적 사유와 함께 반환` (에이전트 계약: reason field)

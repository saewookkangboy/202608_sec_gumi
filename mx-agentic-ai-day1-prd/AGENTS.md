# Repository Instructions

## 목적

오전 기획서를 AI PRD Canvas v1으로 옮기고, Day 2~4 실습에 연결할 가상 샘플과 목표 출력을 만든다.

## 안전 규칙

- 실제 사업장 정보, 개인정보, API 키, 자격증명을 넣지 않는다.
- 모든 `sample-data/`는 명백히 가상의 이름·수치만 사용한다.
- `docs/proposal.pdf`는 오전에 만든 기획서만 넣는다. 기밀 문서를 복사하지 않는다.
- 8·9·10번 Canvas는 억지로 채우지 않고 "지금 아는 것 / 아직 모르는 것"만 기록한다.

## 산출물

| 경로 | 설명 |
|---|---|
| `docs/prd.md` | PRD 본문 (Day 2~4에서 8·9·10을 이어서 수정) |
| `docs/prd.pdf` | Canvas 1장 제출용 |
| `sample-data/` | 가상 입력 샘플 |
| `expected-output/` | 목표 출력 예시 |

## 작업 순서

1. `docs/proposal.pdf`(또는 대화 내용)에서 1~4번 이관
2. 5·6·7번 인터뷰로 AI 역할·데이터·출력 정의
3. 8·9·10 예약석 메모
4. 자가 점검 8항목 통과 후 파일 생성

Claude Code는 같은 폴더의 `CLAUDE.md`가 이 파일을 가져온다.

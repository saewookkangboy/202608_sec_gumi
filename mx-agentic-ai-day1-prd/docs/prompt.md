# 복사용 프롬프트 (Day 1 · AI PRD Canvas)

[Notion 3_AI PRD 가이드](https://adorable-hail-415.notion.site/3_AI-PRD-3c4137efedf680f7a491f3bd50c832c9)와 동일합니다. 오프라인에서도 사용할 수 있도록 저장소에 포함했습니다.

```text
당신은 AI 제품 기획 전문가입니다.
이 폴더의 docs/proposal.pdf (또는 docs/proposal.md, 앞선 대화 내용)를 토대로,
AI PRD Canvas v1을 완성합니다.

먼저 docs 폴더 안의 기획서를 읽고 시작하세요.
질문은 반드시 [한 번에 하나씩] 하고, 제 답을 짧게 정리해 확인받은 뒤
다음 질문으로 넘어가세요. 제가 막히면 구체적인 예시를 2~3개 제시해
고르게 해 주세요.

━━━ 1단계. 1~4번 이관 (빠르게) ━━━
기획서 내용을 아래 4칸으로 옮겨 채운 뒤, 한 번에 보여주고
"이대로 맞나요?"라고 확인만 받으세요. 질문을 길게 하지 마세요.
  1 배경 — 어떤 문제가 있는가
  2 목표 — 시간/품질/리스크 중 무엇이 우선인가 + MVP 한 문장
  3 사용자 — 주 사용자, 검토자, 승인자
  4 업무 흐름 — 현재(As-Is) / 목표(To-Be: 입력 → AI → 사람 검토 → 출력)

━━━ 2단계. 5·6·7번 집중 인터뷰 ━━━
한 칸씩 파고드세요.

[5. AI 역할]
- "AI가 대신할 일을 동작 단위로 나눠 볼까요?"
- "반대로, AI가 절대 하면 안 되는 일은 무엇인가요?"
  → 답이 막히면 예시 제시: 실제 발송/전송, 숫자 임의 수정,
    없는 정보 추측해서 채우기, 최종 승인 등
- "그중 사람이 계속 해야 하는 일은?"

[6. 데이터 / 컨텍스트]
- "어떤 자료가 필요한가요? 항목(컬럼)은 무엇인가요?"
- 구조를 들은 즉시, sample-data/ 폴더에 **가상 샘플 파일**을
  직접 만들어 저장하고 내용을 보여준 뒤 "이런 형태 맞나요?"라고 확인.
  ※ 실제 데이터는 절대 요구하지 말 것. 명백히 허구인 이름·수치 사용.
- "그 자료를 볼 권한이 있나요? 민감한 항목은 무엇인가요?"
- "자료가 없거나 칸이 비어 있으면 AI가 어떻게 해야 하나요?"

[7. 출력 명세]
- "결과물이 어떤 모양이어야 하나요? 구조를 말해 주세요."
- 들은 즉시, 6번 가상 데이터를 넣었을 때 나와야 할 **목표 출력 예시**를
  expected-output/ 폴더에 파일로 만들어 보여주고 "이거 맞나요?
  뭘 고칠까요?"라고 확인. 피드백을 받아 다시 고치세요.
- "결과의 근거(어느 입력에서 왔는지)도 함께 표시할까요?"
- "AI가 애매하거나 확신이 없을 때는 뭐라고 답하게 할까요?"
  → 추측하지 않고 '[확인 필요]'로 표시하는 방식을 제안해 보세요.
- "말투와 분량은 어느 정도가 좋을까요?"

━━━ 3단계. 8·9·10 예약석 (짧게) ━━━
세 칸은 채우지 말고, 각각 아래 두 줄만 물어보세요.
  8 평가 기준 (Day 2에서 학습) / 9 안전·거버넌스 (Day 4)
  10 운영 지표 (Day 4)
  - "지금 감으로 아는 것은?" (한 줄)
  - "아직 모르겠는 것은?" (한 줄)

━━━ 3.5단계. 자가 점검 (파일 만들기 전 필수) ━━━
파일을 만들기 전에, 지금까지 정리된 PRD를 아래 항목으로
스스로 점검하고 결과를 표로 보여주세요.
각 항목에 ✅ 통과 / ⚠️ 보완 필요 를 표시하고, 미달이면 무엇이
빠졌는지 한 줄로 지적하세요. 좋게 봐주지 말고 엄격하게 판정하세요.

[점검 항목]
1) 목표(2번)에 완료 조건이 '숫자'로 있는가
2) MVP가 한 문장으로 읽히는가
3) AI 역할(5번)에 '하지 않는 일'이 적혀 있는가 (최소 2개)
4) 데이터(6번)에 권한과 민감도가 적혀 있는가
5) 데이터(6번)에 '누락 시 규칙'이 있는가
6) 출력(7번)에 형식이 구체적인가
7) 출력(7번)에 fallback 규칙이 있는가
8) 8·9·10번에 '아직 모르는 것'이 솔직하게 적혀 있는가

━━━ 4단계. 파일 생성 ━━━
인터뷰가 끝나면 이 폴더에 아래를 만들어 주세요.

① docs/prd.md — PRD 본문 (Day 2에 이어서 수정할 원본)
② docs/prd.pdf — 캔버스 1장 (제출용)
   Python 스크립트: python3 scripts/generate_canvas_pdf.py docs/prd.md docs/prd.pdf
③ sample-data/ — 가상 입력 샘플
④ expected-output/ — 목표 출력 예시

완성 후 python3 scripts/validate_day1.py 를 실행해 검증하세요.

주의: 진행 내내 사내 기밀·개인정보·고객 데이터는 쓰지 말라고
저에게 상기시켜 주세요. 모든 실습 데이터는 가상으로 만듭니다.
```

예시 산출물: [`docs/examples/quotation-bot/`](./examples/quotation-bot/)

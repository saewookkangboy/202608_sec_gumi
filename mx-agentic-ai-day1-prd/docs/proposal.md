# 기획서 · 견적요청 초안봇

**작성:** 구매팀 (합성 예시)  
**날짜:** 2026-08-24

## 배경

매주 협력사에 보내는 견적 요청 메일을 작성하는 데 30분 이상 소요됩니다. 형식은 같고 품목만 바뀌는 반복 업무입니다.

## 목표

- 작성 시간 **30분 → 5분**으로 단축
- 수정 없이 발송 가능한 수준의 초안 품질
- 발송 전 사람이 반드시 검토

## 사용자

- 주 사용자: 구매팀 5명
- 검토·승인: 본인 검토 후 파트장 최종 확인

## 업무 흐름 (To-Be)

품목 Excel → AI 초안 생성 → 사람 검토 → 메일 발송

## MVP

품목 리스트를 넣으면 견적 요청 메일 초안이 나오는 봇

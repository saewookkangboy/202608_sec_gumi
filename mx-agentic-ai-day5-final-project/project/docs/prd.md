# AI PRD · 견적요청 초안봇

> Canvas v1 — Day 1 결과물 예시. 8·9·10은 Day 2·4에서 채웁니다.

## 1. 배경

매주 협력사에 보내는 견적 요청 메일 작성에 30분 이상 소요됩니다. 형식은 동일하고 품목만 바뀌는 반복 업무입니다.

## 2. 목표

- **시간:** 30분 → 5분
- **품질:** 수정 없이 발송 가능한 초안
- **리스크:** 발송 전 시각적 사람 검토로 통제

**MVP 한 문장:** 품목 Excel을 넣으면 견적 요청 메일 초안이 나오는 봇

## 3. 사용자

| 역할 | 설명 |
|---|---|
| 주 사용자 | 구매팀 5명 |
| 검토자 | 본인 |
| 승인자 | 파트장 (발송 전 최종 확인) |

## 4. 업무 흐름

```text
As-Is:  품목 확인 → 메일 직접 작성 → 검토 → 발송 (30분+)
To-Be:  품목 Excel → AI 초안 → 사람 검토 → 메일 발송
```

## 5. AI 역할

**할 일:**
- 품목 리스트를 읽고 표준 템플릿 기반 견적 요청 메일 초안 작성
- 기존 메일 2건의 톤·구조 참고

**✕ 하면 안 되는 일:**
- 메일 직접 발송·전송
- 단가·수량 임의 수정·추정
- 없는 정보를 지어내기

**사람이 계속 하는 일:** 최종 검토, 발송, 협력사 민감 정보 확인

## 6. 데이터 / 컨텍스트

| 소스 | 항목 | 권한 | 민감도 |
|---|---|---|---|
| 품목 Excel | 품명, 규격, 수량, 희망납기 | 본인 작성 문서 | 협력사명·단가 민감 → **가상 데이터만** |
| 기존 메일 2건 | 인사말·표 형식·회신 기한 | 본인 발송 이력 | 가상 예시로 대체 |

**누락 시 규칙:** 규격·납기 없으면 채우지 않고 `[확인 필요]` 표기

**샘플 파일:**
- `sample-data/품목리스트_가상.csv`
- `sample-data/기존메일_예시.txt`

## 7. 출력 명세

**형식:**
1. 제목 1줄
2. 본문: 인사 → 요청 표 → 회신 기한 → 연락처
3. 각 품목에 입력 행 번호 각주

**근거:** 품목 표 각 행에 Excel 행 번호 주석

**Fallback:** 애매하거나 확신 없으면 `[확인 필요]`, 하단에 목록 정리

**톤:** 정중한 업무체, 5문장 이내

**목표 예시:** `expected-output/견적요청메일_목표.txt`
